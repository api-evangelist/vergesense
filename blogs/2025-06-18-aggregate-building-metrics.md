New Following the introduction of aggregate space metrics, we have now also added an endpoint for aggregate building metrics /metrics/aggregate/buildings . This endpoint takes building ID, start date, and end date as required parameters and returns metrics for the building aggregated over the given time period. Like aggregate space metrics, this is meant to provide a quick, high-level summary of usage.
