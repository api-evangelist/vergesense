New A new "Send Frequency" option was added to the configuration for the space report event webhook. This configuration option supports two options: Always: Webhook will be sent every time the event occurs. (Default) On Change: Webhook will only be sent when the space's person count or signs of life value has changed or if the event is the first event in a new hour.
