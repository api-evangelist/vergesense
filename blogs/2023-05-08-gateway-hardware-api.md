New The VergeSense /hardware/sensors api now surfaces MAC Address information for sensor devices. More details can be found here Additionally, the VergeSense /hardware api now has a new endpoint: /hardware/gateways . This endpoint shares all the same keys and pagination details as the existing /hardware/sensors endpoint, but it is specific to gateway devices.
