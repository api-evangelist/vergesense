Deprecation On April 1, 2026 we will be deprecating various attributes associated with space types. This impacts our /spaces/types API endpoint along with our CSV export capability within the VergeSense platform. /spaces/types API endpoint Today, we return 4 attributes for each space type: for_groups shared_space open_seating reservable The attributes are being removed and replaced by a single normalized_space_type attribute.
