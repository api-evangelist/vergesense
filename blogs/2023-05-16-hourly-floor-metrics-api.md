New VergeSense has just released an hourly floor metrics API endpoint: /metrics/hourly/floors . This endpoint is similar to the hourly space metrics API endpoint but provides VergeSense analytics grouped to the floor level for the selected time range. This endpoint can not only be used to get space metrics aggregated to the floor level, but can also provide information regarding floor metrics for EN1 deployments.
