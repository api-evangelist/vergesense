New We have recently introduced an aggregate space metrics API endpoint /metrics/aggregate/spaces along with an hourly neighborhood metrics API endpoint /metrics/hourly/neighborhoods . The aggregate space metrics endpoint will aggregate each space's metrics within the time period. The result s are metrics for the entire time period not broken down by say, hour.
